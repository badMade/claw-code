## 2024-05-14 - Python cached_property and frozen dataclasses
**Learning:** In Python, `functools.cached_property` works perfectly on `@dataclass(frozen=True)` instances because it bypasses `__setattr__` and writes the cached value directly to the instance's `__dict__` (as long as `__slots__` aren't being used). Also, when refactoring O(N) linear list searches into O(1) dictionary maps using comprehension, iterating backwards (`reversed()`) elegantly preserves the list's original first-match precedence for duplicate items.
**Action:** When optimizing lookups in read-heavy frozen dataclasses, reach for `@cached_property` without fear of `FrozenInstanceError`, and remember to reverse lists when preserving first-match semantics during dict creation.
